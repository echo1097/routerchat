# Contributing to RouterChat

RouterChat is no longer actively maintained and is not accepting pull requests, bug reports, or feature requests.

## Forking

RouterChat is licensed under the [Apache License 2.0](LICENSE). If you want to continue developing it or make changes for yourself, you are welcome to fork the repository and follow the [developer guide](docs/developer.md) to run it from source.

If you distribute a modified version, please follow the name and branding section of [TOS.md](TOS.md#7-name-and-branding) and keep the notices required by the Apache License 2.0.
