# Security Policy

> [!NOTE]
> RouterChat is no longer actively maintained. This repository and [get-routerchat](https://github.com/echo1097/get-routerchat) will not receive security updates, patches, or vulnerability reviews.

## Using RouterChat

RouterChat is provided as-is. If you continue to run it:

- **Never share `user-data/.env` (your API keys) or `user-data/routerchat.sqlite3` (your chats and stories).**
- If an API key may have been exposed, revoke it immediately at [openrouter.ai/keys](https://openrouter.ai/keys) or [platform.claude.com/settings/keys](https://platform.claude.com/settings/keys).
- Keep phone access turned off unless you are on a local Wi-Fi network you trust, as local traffic is not encrypted.
- Releases are verified by SHA-256 checksum and are not signed or notarized.
